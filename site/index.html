Brand guide

OIML Smart

The official logo assets, colors, and animated brand marks of OIML Smart. Every file lives in the branding repository — this page is its published guide.

01 — Usage

Which logo to use

ContextUse
Primary lockup (hero, cover, official)oiml-logo_full-{theme}
App icon / favicon / square tileoiml-logo_icon-{theme}
Small mark, avatar, badge (< 64 px)oiml-logo_globe-{theme}
SMART wordmark + globeoiml-logo_smart-new-{theme}
Component-branded surfacethat component's variant (gallery below)
Loading / progress statesspinning-globe components (section 03)
Social profile picturelogo/profile-pic.png

Every variant ships in -dark (for dark backgrounds) and -light (for light backgrounds). Place -dark artwork on #050810, -light artwork on #f5f3ed — never mix. -old and numbered files are historical and must not be used in new work.

03 — Motion

Animated brand mark

Three dependency-free ES5 components animate the globe — wireframe with the OIML⇄SMART wordmark, a 3D filled globe for spinners and progress, and a mini variant for small screens. One parameter, cycleTime, synchronizes spin, wordmark, and fill.
